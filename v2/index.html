    FAQ

    Pertanyaan yang sering muncul.

    Belum menemukan jawabannya? Tim kami siap membantu.

    Kapan saldo aktif?

    Pada produk nyata, saldo aktif setelah pembayaran dikonfirmasi — biasanya dalam hitungan menit. Pada prototype ini, konfirmasi hanya menampilkan status sukses simulasi.

    Model AI apa saja yang bisa dipakai?

    Satu saldo bisa dipakai untuk semua model yang tersedia, misalnya Claude, GPT, Gemini, DeepSeek, dan Qwen. Paket apa pun, pilihan modelnya sama. Model hemat membuat saldo lebih awet; model premium lebih kuat untuk tugas rumit.

    Apakah saldo bisa kedaluwarsa?

    Tidak. Saldo dan bonus kredit tidak kedaluwarsa. Saldo tidak bisa diuangkan atau dipindahkan ke akun lain.

    Apakah harga sudah termasuk PPN?

    Ya. Harga paket sudah termasuk PPN, tanpa biaya tambahan. 1 kredit setara Rp1.

    Apakah estimasi jumlah sesi pasti?

    Tidak. Panjang prompt, model, dan format output memengaruhi pemakaian. Estimasi di halaman ini memakai satu “sesi kecil” (±40 rb token masuk, ±4 rb token keluar) sebagai patokan.

    Apakah saldo terpotong kalau permintaan gagal?

    Tidak. Permintaan yang gagal dan tidak menghasilkan jawaban tidak memotong saldo.

    Metode pembayaran apa saja?

    QRIS, e-wallet (DANA, GoPay, OVO), dan virtual account. Di prototype ini semuanya simulasi.

    Bisakah refund atau batal?

    Pembayaran yang belum selesai bisa dibatalkan kapan saja. Saldo yang sudah masuk tidak bisa diuangkan. Kebijakan refund lengkap akan ditetapkan sebelum peluncuran; prototype ini tidak memproses transaksi nyata.

    Ke mana data prompt saya dikirim?

    Prompt dikirim ke penyedia model yang kamu pilih untuk diproses, dan bisa diproses di pusat data di luar Indonesia. Kami tidak memakai prompt atau hasilnya untuk melatih model. Pada prototype ini tidak ada data yang dikirim.

    Bagaimana kalau API key saya bocor?

    Nonaktifkan API key itu dari halaman saldo, lalu buat yang baru. Semua pemakaian lewat API key memotong saldomu, jadi simpan seperti kata sandi.

    Bisakah membeli untuk tim dan meminta invoice perusahaan?

    Bisa. Kami bantu siapkan invoice atas nama perusahaan, faktur pajak, dan pemantauan pemakaian per anggota. Klik “Konsultasi untuk tim” dan kami hubungi dalam 1 hari kerja.
